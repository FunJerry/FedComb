# 如何扩展实验

## 1. 新增普通消融：只改实验表

例如在 `experiments/ablations.json` 的 variants 加入：

```json
{
  "name": "no_time_term",
  "overrides": {"allocation.time_weight": 0}
}
```

先用 `fedcomb suite experiments/ablations.json --list` 检查完整展开配置。无未知字段、无重复实验名、无非法 IPC 组合后再训练。

不要复制 `client.py` 成 `client_no_time.py`，也不要把多个变体写进客户端循环里。

## 2. 新增参数讨论：grid

```json
{
  "base": "../configs/paper.json",
  "seeds": [42, 43, 44],
  "variants": [{"name": "temperature", "overrides": {}}],
  "grid": {"distillation.temperature": [1, 2, 4]}
}
```

组合数 = 变体数 × 所有网格取值数的乘积 × 种子数。不要第一次就放入 5 个参数各 5 个值，实验量会指数增长。

网格点按稳定序号命名，具体字段取值保存在 `resolved_cases.json` 和各自 config.json。变体和 grid 不允许覆盖同一个字段。

## 3. 判断消融是否只改了预期内容

查看两组 `config.json`，核对：

- 数据集、样本量、初始化模型和种子是否相同。
- `manifest.json` 的数据划分和初始模型哈希是否相同。
- 同一轮参与者和实际资源轨迹是否相同。
- 候选范围、实际学生开销、成功参与人数是否发生了连带变化。

“无蒸馏 + 重新调度”允许组合变化，研究端到端效果。固定路径、足够容量的头/尾/无蒸馏比较，研究学习效果。不要把两者混称同一个单因素实验。

## 4. 新增调度算法

修改 `strategies/allocation.py`：

1. 在 `Allocator.select()` 新增明确的策略分支。
2. 使用 `candidates()` 提供的统一可行集合，不能偷换最短长度或漏掉学生成本。
3. 返回同样的 Allocation，包括分项分数或其它可解释记录。
4. 在 `AllocationConfig` 的 policy 校验中声明新名称。
5. 增加一个测试：候选可行、无可行时 None、选择不暗改全局权重。

无需修改 `RoundRunner.run()` 或 `ClientTrainer.train()`。

## 5. 新增蒸馏损失或学生规则

学生规则只改 `select_student()`；权重只改 `student_weight()`；损失只改 `compute_student_loss()`。

若需要“同时训练头和尾”，那会改变 Plan、成本和回传协议，不是加一个布尔开关就完成。当前明确支持“每客户端一个额外学生”，不要在已有字段里隐式塞第二个学生。

必须检查：教师 detach；共享 D 参数冻结；学生优化器只含学生；λ=0 行为明确；额外成本一致。

## 6. 新增聚合算法

只修改 `strategies/aggregation.py` 和 `AggregationConfig`。所有客户端更新统一来自 ClientUpdate。

若使用不同载荷，例如额外梯度，应同步修改 `simulation/costs.py`，并测试通信量。不能只改聚合公式，却仍报告普通模型包通信量。

IPC 对照优先使用现有 `ipc_comparison.json`：双方均用新鲜资源、随机可行集合、首批梯度、同样载荷，只有逆概率权重不同。

## 7. 新增数据集或模型

数据集加载改 `data/datasets.py`，补对应归一化、标签接口、Config 校验，不修改客户端训练。

模型构造改 `models/network.py`，必须保留组件协议与特征接口，随后检查成本和全部局部路径。

当前主架构固定 16 个块。改变分片数量时必须同步修改 Plan 索引范围、成熟度编号、分配枚举和模型终点；不能只改 `[3,4,6,3]` 然后继续声称所有策略兼容。通道 width 和类别数已有配置入口。

## 8. 推荐的实验顺序

先单元测试 → 合成数据矩阵 → 真实数据少轮 → 多种子正式运行 → 汇总指标和不确定性。

新实验使用新的结果目录。已有结果拒绝覆盖。CIFAR-10 启动脚本支持显式 `--resume`：从完整检查点恢复，并回退检查点之后的日志；详见 [云端测试指南](CIFAR10云端测试指南.md)。
