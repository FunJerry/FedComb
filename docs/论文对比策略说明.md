# 论文对比策略调整（2026-10-15）

> 本页以下内容记录此前已完成实验的旧配置。用户随后确认了修正型评分和原作者 Greedy（起点 0～15、允许短区间、最大参数包）；当前实现以 [算法意图对齐修改说明](算法意图对齐修改说明.md) 为准，不要把下面旧目录用作新实验输出。

只调整 Random、Greedy 的主区间选择流程，不修改 FedComb 综合评分、模型、数据划分、蒸馏、聚合及资源模型。仍统一使用配置中的最小长度（当前 3）。

## Random：先抽一次，再验证容量

1. 参考原作者 `get_random_model_parts`，在 3～16 中均匀抽长度 L。
2. 在 0～16-L 中均匀抽起点 s，终点 e=s+L-1。
3. 按原有成熟度规则选择额外学生，计算含 E/D、边界头尾、主区间和学生的整个模型包成本。
4. 超预算则剔除当前客户端，不重抽、不缩短、不改起点；符合预算则训练。

这不是全部区间均匀，也不是可行区间均匀。容量不影响抽样分布，只影响抽样后的接纳。首轮学生权重为 0 的规则不变。

## Greedy：随机起点，固定起点内选最长可行区间

1. 为保留统一的最少 3 片约束，在 0～13 中均匀抽起点 s，不按容量预筛起点。
2. 扫描该起点的所有合法终点；每次均重新选择配套学生并计算成本。
3. 在符合预算的区间中选终点最大的一个，即主分片数量最多的区间。
4. 该起点没有可行区间就剔除客户端，不换起点重试。

不能在第一个超容量区间处停止：边界尾和额外学生可能变化，包大小不保证随终点单调。

论文文字未规定随机区间的具体概率分布，本工程 Random 的“长度再起点”采用原作者源码。Greedy 按用户要求将“最大区间”明确为最长区间；原作者旧代码还存在起点可落在末两片、按参数包大小比较等实现细节，不能宣称逐行照搬。本次保留现有最少 3 片约束，而不是引入 1～2 片区间。

## IPC 保留独立采样口径

原来的“先筛可行区间、再均匀采样”独立命名为 `random_feasible`。`ipc`、`gradient_mean` 两个首批梯度对照仍使用它并要求 fresh 资源报告，入选概率计算不变。实验表已同步更新；论文三方法入口仍为 dynamic/random/greedy + mean。

## 日志与旧结果

Random 超预算日志为 `random_interval_exceeds_reported_budget`，包含抽中的区间、学生及模型包大小。Greedy 无可行区间日志为 `no_feasible_interval_at_random_start`，包含随机起点。被剔除者不进入本地训练、聚合和成功更新计数。

Random 不枚举整个可行域，成功记录中的 feasible_count 为 null；Greedy 该值仅统计抽中起点下的可行区间数。服务器最后收到的资源报告用于初次判定；训练前对当前实际模拟资源的二次复核保持原样。

旧 `results/cifar10_s42` 及其图表全部保留，它们仍属于旧的“可行域随机/全局最大参数包”实现。不得改名冒充新实验，不得在旧结果上续训。
