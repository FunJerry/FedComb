# 已有实验结果绘图

在工程根目录执行，无需模型权重，不会重新训练或修改 CSV/JSON 原始结果：

```bash
.venv/bin/python scripts/show_results.py results/cifar10_s42 --plot --window 20 --output-dir results/cifar10_s42/figures
```

若缺少绘图库，先执行 `.venv/bin/python -m pip install '.[plots]'`；不要使用本机锁文件替换云端 CUDA PyTorch。图片采用英文标签以兼容没有中文字体的云服务器，图表与指标对应如下。

| 文件名（均有 PNG、PDF） | 含义 |
|---|---|
| comparison | 六组对比总览 |
| accuracy_round | 完整主模型测试准确率—全局轮次 |
| loss_round | 完整主模型测试交叉熵—全局轮次，不是本地训练损失 |
| accuracy_measured_time | 测试准确率—累计实测轮耗时，小时 |
| accuracy_simulated_time | 测试准确率—累计模拟耗时，小时 |
| accuracy_communication | 测试准确率—累计估算通信量，GiB |
| accepted_clients | 每轮成功训练的客户端数量，不是抽取数量 |

`summary_comparison.csv` 提供最后/最佳准确率、最佳轮次、末 50 轮平均准确率、两种耗时、估算通信量、成功更新数量和成功率。精度统一换算成百分数，1 GiB = 2^30 字节。少于 50 轮时均值使用已有轮次。

浅色曲线显示所有原始点，深色曲线是包含当前轮的后向 20 轮平均；前 19 轮使用已有点，不补零、不使用未来数据。`--window 1` 关闭平滑。CSV 中的最佳/最后准确率始终来自原始值，不从平滑曲线取值。

实测轮耗时是日志中各轮 wall_seconds 之和，含该轮训练、聚合和测试，不是端到端作业耗时，不含初始化、轮外检查点写盘等开销。模拟时间和通信量来自资源/成本模型，不代表真实多设备网络测量。

脚本核对轮次连续性、有限数值、0～1 准确率、成功与跳过人数；有 summary 时还检查轮数、准确率、累计时间和通信量。未完成实验会明确标注 incomplete。

当前正式实验只有 seed=42，不绘制跨种子置信区间，也不能用一个种子的最高精度证明方法总体优劣。比较目录应只包含本次正式实验，不能混入 verification_matrix 的合成机制验证。
