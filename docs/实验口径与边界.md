# 实验口径与边界

## 保留的原作者实验主线

初始化全局模型 → 随机选参与客户端 → 逐客户端选择连续区间与辅助学生 → 本地 5 epoch 任务/蒸馏 → 轮末按组件聚合 → 更新状态 → 完整主模型测试。

默认 16 个 Bottleneck、E/D 公共组件；dynamic/random 区间至少 3 片，Greedy 按原作者允许 1～2 片并选择最大参数包。任务优化器包含当前小模型全部组件；学生优化器只更新额外学生。

模型参数和主输入输出结构沿用上一版已验证实现；不保留未启用的 mytimm 注册器、模型集合和重复实验脚本。

## 不照搬的旧实现缺陷

- T15 与 B15 独立，不共享可变参数。
- 无候选、预算变化拒绝正常记录，不解包 None。
- 各策略共用模型包成本；论文 Random 先抽样再验预算，Greedy 只扫描随机起点下的区间。IPC 的可行域随机独立命名为 random_feasible。
- 学生关闭后对应字节、FLOPs、优化器同时移除。
- 候选覆盖计数明确提交；实际学习计数只由成功更新增加。
- 教师张量 detach，D 冻结副本，避免多余 E 前向和错位目标。
- 初值 λ=0 时不 step 学生，不偷偷执行衰减/改变 BN。
- 资源、参与者、数据增强、学生的随机性尽量隔离。

这不是逐数值复刻旧日志。原作者的缺陷不应成为新工程实验标准。

## 资源和时间

资源在单机模拟，参数容量不是训练峰值内存。模型包预算含 E/D、区间 B、边界 H/T、额外学生，不含全部梯度、优化器、激活和缓冲区。

每轮仅被选中的设备有 20% 概率联合变化，内存/算力/带宽默认 ±20%/±30%/±25%，不裁剪到初始范围。为修正旧脚本分配后容量改变仍继续训练的问题，变化在分配前执行；事件上报和实际预算复核保留。静态消融使用 environment.change_probability=0。

前向 FLOPs 按实际组件/输入统计，再用约 3 倍估训练计算；不是实际硬件测速。事件报告的控制报文、完整额外教师开销不完全进入成本模型。

日志同时记录本机实测时间和同步轮次估算时间，后者取最慢客户端成本，但程序实际顺序执行。

上下行各计一次；首批梯度模式额外上传梯度。不要把包字节和链路 MB/Mb 混用。

## 蒸馏温度与分类器

默认温度 2，参考论文；旧脚本为 4，配置可比较。KL 保留 τ² 缩放，不能宣称与论文无 τ² 的公式逐数值相同。

分类器 dropout 默认 0，原作者 get_stem 抽取的 pool+fc 实际没有调用配置为 0.1 的完整 forward_head dropout。

## 成熟度与动态评分

成熟度是次数与任务损失变化代理，不是组件独立准确率。损失变化使用本次本地训练首/末任务 batch 的绝对差；所有实际训练组件使用该客户端代理。学生仅在蒸馏步数大于 0 时计数，λ=0 的学生不上传为已训练更新。

样本权重只归一化一次，等样本时等价于原作者均值。成熟度评分的 delta 使用 M 队列均值；主块缺口为 max(0,delta-phi)，辅助阈值为 aux_count_weight*delta。覆盖评分对完整 16 维缺口求正向惩罚，不复刻原负号奖励漏覆盖的行为；本轮覆盖计数有效递增。轮末覆盖率分母包括所有选中设备，失败者贡献 0。

时间归一化初值来自完整主模型在配置初始最低算力/带宽下的统一成本参考，含上下行，之后按观测最大候选时延更新 EMA。首次参与计算量不为 0；不把该启发式评分宣称为收敛保证。完整说明见 [本次修改](算法意图对齐修改说明.md)。

去掉队列评分项只是把对应 weight 置 0；队列仍记录，成熟度仍可用于学生选择和 λ。这样日志可对照，但实验命名必须准确。

## IPC 对照

`mean` 是多步客户端状态平均；不能拿它与首批梯度 IPC 的全部差异，都归因于逆概率权重。

因此提供 `gradient_mean`：与 `ipc` 一样保存第一次任务更新前的主参数梯度，只是不除入选概率。两者都必须使用 random_feasible + fresh，发送同样载荷，降低额外混杂。

IPC 主更新为 Σ(q/p)g，不再归一化 q/p。普通首批梯度为 Σqg，未入选的分片贡献 0。参数 g 来自辅助代理路径，可能随区间改变；采样掩码校正不自动证明完整模型梯度无偏。

这两条路线后续主参数本地多步变化不用于全局主参数；E/D、辅助和 BN 缓冲区仍用多步状态平均。公式、载荷与研究边界都应在正式论文写清。

## 尚未实现或验证

真实设备网络、真实资源限额、MultiSplitFed/RingSFL 分布式基线、AMP、论文规模精度结果、CUDA/MPS 数值一致性、理论收敛保证均不在当前已验证范围。新增检查点续训已通过 CPU 中断重放测试；CUDA 客户端记录分配器峰值显存，但不等同于整机显存或真实边缘设备资源测量。

支持 CIFAR-10/100/SVHN 数据入口，不等于已完成这些数据集的复现实验。合成图准确率不作研究结论。
