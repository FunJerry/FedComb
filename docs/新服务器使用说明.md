# 新服务器：CIFAR-10 三方法实验

新版工程路径 `/root/autodl-tmp/fedcomb_intent_v2`，代码与完整 CIFAR-10 位于数据盘；本机对应工程为 `/Users/zwp0728/Project/Fedcomb工程`。旧目录 `/root/autodl-tmp/fedcomb_cifar10` 的代码和实验结果保留，不与新版混用。

## 本次方法定义

- FedComb：使用 [修正型原算法评分](算法意图对齐修改说明.md)，不是此前已完成实验的旧评分。
- FedComb-Random：参考原作者源码，先随机长度，再随机合法起点；只抽一次，超预算直接跳过客户端。
- FedComb-Greedy：随机起点 0～15，允许 1～2 片，只在该起点下选择最大可行参数包；找不到就跳过，不重抽起点。
- dynamic/random 最少 3 片，Greedy 按用户确认使用原作者长度约束。三组共用数据划分、学生选择、蒸馏和 mean 聚合。IPC 的 random_feasible 不用于本次三个方法。

正式配置：CIFAR-10 Non-IID、Dirichlet α=0.5、100 个客户端、每轮抽 10 个、每人 500 张、batch=100、本地 5 epoch、ResNet-50 width=64、每方法 1000 轮、seed=42。


## 分别启动三个方法

以下为三个独立入口，单 GPU 应等上一个完成后再执行下一个，不要同时粘贴执行三条命令：

```bash
bash scripts/run_fedcomb.sh --profile paper --seed 42 --output intent_v2_separate_s42/fedcomb --background
bash scripts/run_random.sh --profile paper --seed 42 --output intent_v2_separate_s42/random --background
bash scripts/run_greedy.sh --profile paper --seed 42 --output intent_v2_separate_s42/greedy --background
```

“顺序运行全部”和“分别启动”选一种，避免重复跑同样实验。换 seed 或实验条件时使用新的输出目录；不要混用旧服务器 results/cifar10_s42 的旧策略结果。

