# 本地数据准备

日期：2026-10-14。来源：`/Users/zwp0728/Documents/RingSFL/data`。

以下内容已移动到本工程 `data/`，不是复制；RingSFL 原来的解压目录/对应 MAT 文件不再存在。CIFAR 压缩包仍留在原目录，可作为恢复来源。

| 数据集 | 本工程位置 | 训练数 | 测试数 | 校验 |
|---|---|---:|---:|---|
| CIFAR-10 | data/cifar10/train、test | 50000 | 10000 | PNG 完整解码验证、RGB、32×32，10 类映射一致 |
| CIFAR-100 | data/cifar-100-python | 50000 | 10000 | train/test/meta 的 MD5 与 torchvision 标准匹配 |
| SVHN | data/train_32x32.mat、test_32x32.mat | 73257 | 26032 | 两个文件 MD5 与 torchvision 标准匹配 |

CIFAR-10 PNG 使用 ImageFolder 兼容入口，并复用原有增强、归一化和等量 Dirichlet 划分。PNG 通过完整性检查不等于证明其内容哈希与官方 Python 原包完全相同；应在报告中保留此存储来源说明。

SVHN MAT 读取需要 SciPy，已加入独立环境与依赖声明。加载这些本地数据不需要启用 download。

原目录保留 MNIST、FashionMNIST、重复 CIFAR 压缩包、损坏/未完成的 CIFAR-10 下载文件。它们当前不用于本项目；没有删除。

移动数据与兼容性检查没有启动论文规模训练，也没有更改现有实验参数。CIFAR-10 的 paper 配置可以继续保持 `data.download=false`。

注意：默认每客户端 500 张、100 客户端，在 SVHN 上只选取 50000 张训练样本，其余未使用；这是当前配置，而非把 SVHN 全训练集都分给客户端。
