# 验证记录

日期：2026-10-14。合成数据仅检查流程，不作为论文精度。

## 自动测试

`python -m unittest discover -s tests -v` 检查：

- 分组配置、非法策略组合、未知字段、覆盖项不污染其它变体。
- 多种子、网格、变体展开数量和实验标识。
- 无蒸馏真实移除学生预算；头/尾模式选择正确。
- 105 个区间 × 头尾特征形状，T15/B15 参数不共享。
- 消融覆盖评分项时其它三个评分项保持一致。
- 蒸馏梯度不进入任务模型；任务梯度涵盖 E/H/B/T/D。
- 两类学生实际更新、客户端不原地修改服务器。
- IPC 固定更新期望恒等式、q/p 不重新归一化。
- 数据增强与训练随机流独立。
- 相同种子的初始模型、划分、资源和参与者可配对。
- 真实 width=64 参数总量 94,114,088 字节，完整前向及局部任务反向。

测试只验证给定机制，不证明收敛或完整模型梯度无偏。

## 快速实验矩阵

`experiments/smoke_matrix.json` 包含 9 种策略组合、2 个种子、各 2 轮：共 18 次独立运行、36 轮。

包含 adaptive、无蒸馏、仅头、仅尾、随机、随机 IPC、贪心、固定区间、FedAvg-Drop 风格完整模型预算检查。小模型、合成图像、CPU。完整模型预算不足时整轮零客户端也应正常测试和记录，而不是崩溃。

最后验证目录以实际工程 `results/verification_matrix` 为准，开发中临时目录的结果不作为最终记录。

跨种子汇总保存样本标准差；初始化、划分、实际资源和参与者配对核验；通信量核验双向模型包及额外梯度。
